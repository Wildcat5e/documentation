# Controllers

## Field-Centric Alliance Color Direction

The code generated by the Phoenix Tuner X Swerve Project (specifically in `CommandSwerveDrivetrain`) automatically configures the Operator Perspective (field-centric "forward") based on the Driver Station alliance, but only while the robot is disabled. Blue Alliance sets forward to 0°, while Red Alliance sets it to 180°. Once enabled, this cannot be changed.

If you change the alliance in the simulated Driver Station while the robot is disabled, your teleop controls and autonomous pathing will immediately rotate by 180 degrees. Ensure the correct alliance is selected before enabling to avoid unexpected behavior.

> Read more about [Setting the Operator Perspective](https://v6.docs.ctr-electronics.com/en/latest/docs/api-reference/mechanisms/swerve/using-swerve-api.html#setting-the-operator-perspective).

## Scaled Input (Non-Linear Input)

A simple way to do this is to cube the raw input value.

```java
// Raise input to the third power
Math.pow(rawInput, 3);
```

## Using [Nicholas's Controller](https://github.com/Wildcat5e/2026-rebuilt-robot/blob/671255baf85ac57c4cc5b37cf3424e4658026970/src/main/java/frc/robot/controller/Controller.java)

### Basic Usage

Assuming you are passing in a Swerve Drive drivetrain, driving should already work.

#### Changing Keybinds

To change what a controller button does, make a change in that controller's file. To change what command is called by a keybind, make a change in `bindingsSetup()` in `Controller`.

There are abstract methods in `Controller` that are for each action you want bound. These must be implemented in each specific controller (return a Trigger from the controller's button or return a value in the case of an axis). Then you can modify that trigger to call a command in `bindingsSetup()` in `Controller`.

### Controller Axis

Note that the axes are flipped within individual controller implementations to match the [WPILib coordinate system](https://docs.wpilib.org/en/stable/docs/software/basic-programming/coordinate-system.html).
