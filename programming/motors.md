# Motors

## Setup

### IDs and Names

Phoenix Tuner X can be used to set IDs and Nams for the motors. IDs just ned to be unique and shouldn't be changed except when you first set up.

### Persistent Configuration

As of 2026, we modify the configuration on the motor controller for the TalonFX Falcon 500 motors. You can and should reset these to default factory settings before taking apart and before using a newly built robot. You can do this through Phoenix Tuner X
